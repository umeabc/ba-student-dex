## 下载

**最新版本**：前往 [Releases](https://github.com/MilkTea0329/ba-student-dex/releases/latest) 下载 `StudentDex.ipa`

| 项目 | 说明 |
| --- | --- |
| 当前版本 | **V1.0.1** |
| 文件大小 | 约 40 MB |
| 系统要求 | iOS 15.0 及以上（iOS 16 / 17 / 18 最佳） |
| 安装方式 | 需要自签，见下方[安装说明](#安装) |

> ipa 是**未签名**的，必须用你自己的 Apple ID 重新签名才能安装（免费，不需要开发者账号）。

### Android

Android 版与 iOS 共用同一套离线数据与页面，外壳换成 WebView 实现，功能对齐 V1.0.1。

| 项目 | 说明 |
| --- | --- |
| 下载 | 前往 [Releases](../../releases) 下载 `StudentDex-1.0.1-android.apk`（release 签名，直接安装） |
| 系统要求 | Android 7.0（API 24）及以上；系统 WebView ≥ 111 |
| 源码 | [`android/`](android/)，Kotlin 单 Activity + `WebViewAssetLoader`，`web/` 零改动零拷贝 |
| 构建 | `cd android && gradle :app:assembleDebug`（需要 Android SDK 35 + JDK 17+；release 签名读取 `android/keystore.properties`，不入库） |

> 首次安装会替换同包名的旧版本（签名不同需先卸载），收藏与同步数据保存在应用私有目录。

## 安装

完整的图文步骤见 **[《什亭之匣 iOS 自签安装教程》](什亭之匣iOS自签安装教程.md)**（含爱思助手的详细操作与报错排查）。

简单流程：

1. 电脑安装 **爱思助手**（<https://www.i4.cn>，推荐）或 **Sideloadly**
2. 手机连电脑并「信任此电脑」
3. 把 `StudentDex.ipa` 导入工具 → 填 Apple ID → 签名 → 安装
4. 手机上：**设置 → 通用 → VPN与设备管理 → 信任**你的 Apple ID
5. iOS 16+：**设置 → 隐私与安全性 → 开发者模式** → 打开 → 重启

> 免费 Apple ID 签名的 App **7 天过期**，到期用同一工具重新签一次即可（收藏会清空）。

## 功能

| 模块 | 内容 |
| --- | --- |
| **学生** | 281 名学生网格，支持名称 / 日文名 / 英文名 / 外号搜索 |
| **筛选** | 稀有度、学院、攻击类型、防御类型、站位、作用、战术作用、武器，8 个维度多选 |
| **排序** | 实装日期 / 名称 / 稀有度 |
| **学院** | 按 16 所学院分组浏览 |
| **收藏** | 一键收藏，本地保存 |
| **概览** | 一句话简介、基础信息、地形适应、角色评测（综合评分 + 6 种玩法评级）、就业场合、抽取建议、技能速览 |
| **技能** | EX / 普通 / 被动 / 辅助 / 子技能，**逐级切换 LV1–LV10** 查看效果与 COST，附升级材料 |
| **属性** | 初始 → 满级对照、装备词条、专武数值、能力解放、羁绊等级奖励 |
| **养成** | 专武、爱用品、技能材料一览 |
| **资料** | 全名、假名、译名、年龄、生日、身高、兴趣、画师、声优、简介、礼物偏好、情人节巧克力、同名角色（可跳转） |
| **语音** | 按分类查看全部台词：日文原文 + 中文翻译（**官方 / 民间**可切换），支持**日配 / 中配 / 韩配 试听**，并显示三语声优 |
| **影画** | 官方介绍、回忆大厅、表情包（最多 30+ 张）、设定集（日/繁中）、TV 动画、官方衍生、PV / 角色演示视频，以及原本的立绘，全部按分类浏览，点击可放大；**首次查看需联网，之后自动缓存可离线看** |

### 其他特性

- **完全离线**：资料、头像、立绘、图标全部打包在 App 内，断网也能用（语音试听需要联网，音频不随包）
- **数据自动同步**：每次启动会在后台检查 WIKI，有新实装学生或已有学生资料被修改时自动更新，
  新学生带 `NEW` 角标、被修改的学生带「更新」角标
- **版本更新提醒**：App 会检查 GitHub 上的新版本，有更新时弹窗展示更新日志，可一键跳转下载
- **缓存管理**：影画 / 语音素材按需下载并缓存，可在「更多 → 存储」查看占用并一键清理
- **手势**：在详情页从屏幕左边缘右滑返回，跟手拖动
- **深色模式**：跟随系统自动切换，适配刘海与 Home Indicator

## 常见问题

| 现象 | 解决 |
| --- | --- |
| 提示「未受信任的开发者」 | 设置 → 通用 → VPN与设备管理 → 信任你的 Apple ID |
| 提示「无法验证 App」 | 连网后重新打开；或删除后重装 |
| 提示需要开启开发者模式 | 设置 → 隐私与安全性 → 开发者模式 → 打开并重启（iOS 16+） |
| 7 天后打不开 | 签名过期，用同一工具重新签名安装 |
| 打开后一片空白 | 重新下载 ipa 后重新签名安装 |
| 数据不是最新的 | 更多 → 立即同步WIKI数据，或等待下次启动自动同步 |
